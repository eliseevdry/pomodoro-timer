# pomodoro-timer

Простое desktop-приложение Pomodoro Timer на Go с интерфейсом Fyne.

## Возможности

- список задач хранится только в оперативной памяти;
- задачи можно добавлять и удалять;
- задачи можно отмечать выполненными вручную;
- таймер отображается прямо в строке выполняемой задачи;
- управление таймером сделано кнопками-иконками без текста;
- таймер задачи запускается на 25 минут;
- таймер можно поставить на паузу и продолжить;
- у невыполняемых задач показываются только запуск и удаление;
- у выполненных задач остаются checkbox, название и удаление;
- отметка задачи выполненной останавливает ее таймер;
- можно выбирать другие задачи без сброса текущего таймера;
- при запуске таймера у другой задачи предыдущий таймер ставится на паузу и сохраняет оставшееся время;
- во время идущего таймера можно добавлять новые задачи и удалять другие задачи;
- после завершения 25 минут приложение подает звуковой сигнал и не запускает следующий таймер;
- завершение таймера не отмечает задачу выполненной автоматически.
- в интерфейсе нет текстовых подписей на кнопках, только значки.

## Требования

- Go 1.22 или новее;
- системные инструменты сборки для Fyne:
  - macOS: Xcode Command Line Tools (`xcode-select --install`);
  - Linux: C compiler и OpenGL/X11 development packages, которые требуются Fyne;
  - Windows: C compiler, например MinGW-w64.

Звуковой сигнал использует системные команды:

- macOS: `afplay`;
- Linux: `paplay`, `canberra-gtk-play` или `aplay`;
- Windows: PowerShell `Console.Beep`.

## Запуск

Установите зависимости:

```bash
go mod tidy
```

Запустите приложение:

```bash
go run .
```

Запустить тесты:

```bash
go test ./...
```

Собрать бинарный файл:

```bash
go build -o pomodoro-timer
```

После сборки:

```bash
./pomodoro-timer
```

## Использование

1. Введите текст задачи в поле `New task` и нажмите `Добавить` или Enter.
2. Нажмите иконку запуска в строке нужной задачи, чтобы запустить ее 25-минутный таймер.
3. Пока таймер идет, в строке задачи отображаются время, пауза и сброс.
4. Нажмите паузу, чтобы остановить отсчет. Таймер останется видимым, для продолжения снова нажмите запуск.
5. Нажмите сброс, чтобы вернуть таймер задачи к `25:00`.
6. Можно выбрать другую задачу без влияния на идущий таймер.
7. Если запустить таймер у другой задачи, предыдущий таймер остановится на паузе и сохранит оставшееся время.
8. Когда время закончится, приложение подаст звуковой сигнал и покажет уведомление.
9. Если задача завершена, отметьте ее галочкой вручную. Таймер этой задачи остановится, а элементы управления скроются.
10. Чтобы удалить задачу, нажмите иконку удаления в ее строке.

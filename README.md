# pomodoro-timer

Простое desktop-приложение Pomodoro Timer на Go с интерфейсом Fyne.

## Возможности

- список задач хранится только в оперативной памяти;
- задачи можно добавлять и удалять;
- задачи можно отмечать выполненными вручную;
- можно выбрать текущую задачу для работы;
- таймер запускается на 25 минут;
- таймер можно поставить на паузу и продолжить;
- после завершения 25 минут приложение подает звуковой сигнал и не запускает следующий таймер;
- завершение таймера не отмечает задачу выполненной автоматически.

## Требования

- Go 1.22 или новее;
- системные инструменты сборки для Fyne:
  - macOS: Xcode Command Line Tools (`xcode-select --install`);
  - Linux: C compiler и OpenGL/X11 development packages, которые требуются Fyne;
  - Windows: C compiler, например MinGW-w64.

Звуковой сигнал использует системные команды:

- macOS: `afplay`;
- Linux: `paplay`, `canberra-gtk-play` или `aplay`;
- Windows: PowerShell `Console.Beep`.

## Запуск

Установите зависимости:

```bash
go mod tidy
```

Запустите приложение:

```bash
go run .
```

Запустить тесты:

```bash
go test ./...
```

Собрать бинарный файл:

```bash
go build -o pomodoro-timer
```

После сборки:

```bash
./pomodoro-timer
```

## Использование

1. Введите текст задачи в поле `Новая задача` и нажмите `Добавить` или Enter.
2. Выберите задачу в списке слева. Текущая задача помечается префиксом `->`.
3. Нажмите `Старт`, чтобы запустить 25-минутный таймер.
4. Нажмите `Пауза`, чтобы остановить отсчет. Для продолжения снова нажмите `Старт`.
5. Когда время закончится, приложение подаст звуковой сигнал и покажет уведомление.
6. Если задача завершена, отметьте ее галочкой вручную.
7. При необходимости нажмите `Сброс`, чтобы вернуть таймер к `25:00`.
